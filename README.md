# To-Do application

## About this project

A simple **responsive** to-do application built with HTML and CSS, with JavaScript functionality planned.

### Technologies

- HTML
- CSS
- JavaScript (coming soon)

### Features

- [x] Responsive layout
- [x] Task list design
- [ ] Add tasks
- [ ] Remove tasks
- [ ] Mark task as completed
- [ ] Save tasks using localStorage

### Getting started

Open `index.html` in your browser.
